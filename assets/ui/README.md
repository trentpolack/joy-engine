# UI Appearance and Layout
These files are the source of the shared UI values for native and browser builds. Cargo reads them through `crates/joy-ui/build.rs` and writes generated Rust into its ignored build directory. Change an asset and rebuild normally; do not edit generated output. There is no runtime file loading or hot reload; editor palettes are compiled in and chosen at run time from each editor's Theme menu.

- `theme-default.json`: `game` contains the base HUD palette; `editor` contains editor, lab, syntax, and development-overlay colors. Colors use `#RRGGBB`. `fonts` selects bundled faces for editor body text, strong text, display text, code, and game strong text. `opacity` controls the game panel's opacity. Its `editor` block is the default Joy palette (blue and orange).
- `theme-neutral-dark.json` and `theme-neutral-light.json`: alternative editor palettes with a `name` (shown in the Theme menu), `dark` (whether egui's base visuals are dark or light), and an `editor` block with the same keys as `theme-default.json`. The build rejects a palette missing a key. Add a palette by adding a file here and listing it in `PALETTE_FILES` in `crates/joy-ui/build.rs`.
- `layout.json`: numeric dimensions in logical pixels. `type` sets shared text sizes, `space` sets spacing, `radius` sets corners, `border` sets stroke widths, `size` sets shared control dimensions, and `game_panel` sets the base HUD frame geometry. These shared metrics do not replace each tool's screen composition, specific dimensions, or saved pane arrangement.

For example, change `theme-default.json` → `editor.panel` to recolor editor panels, `fonts.code` to select another bundled code face, or `layout.json` → `type.code` to resize code text. Values apply on the next build to Joy Editor, FORM EDITOR, and JOYFX EDITOR through the shared UI implementation.

Rust consumers use `theme::colors` (functions such as `colors::panel()` that read the active palette) for editor colors and `theme::layout` for dimensions. `theme::apply_editor` configures the editor/lab preset from the active palette, `theme::set_palette` switches palettes (`theme::palettes::ALL` lists them), and `editor_shell::restore_theme`/`theme_menu` restore and offer the saved choice (`joy.editor.theme`, shared by Joy Editor and the standalone tools; hosted tools follow the host). Development overlays keep the Joy palette (`palettes::JOY`) in every editor theme; `theme::apply` configures game UI using the top-level game colors. Stable egui family/style IDs and the binding of licensed font files remain in Rust because they are implementation contracts, not tuning values.

Available faces are Archivo, Archivo SemiBold, Archivo Medium, Archivo Bold, Archivo Black, and JetBrains Mono. Adding a face requires bundling the font, registering it in the runtime catalogue and build validation, and including its license in build notices. Selecting an existing face only requires editing `theme-default.json`.
