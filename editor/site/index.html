Joy Editor Documentation

New and Import

New creates a starter asset in this project. Choose FORM LAB document (.formlab) to keep the script, parameter overrides, materials and variants together. Level, Object and Particle effect create their respective documents.

Import copies an existing .form, .formlab, .joyfx, .joylevel or .joyobject file into the project. A raw .form keeps its script format: parameter sliders affect its preview; edit script defaults to persist values. Saved Inspector material edits and variants require .formlab.

GLB geometry can be loaded into a FORM mesh parameter. That geometry-only import does not preserve a full scene or its materials; workspace Import accepts the editable formats listed above.

Preview and Save

A preview accepting your changes means the tool can display them. Save File (Ctrl/Command+S) writes them to the project file. Save preserves the document format; it does not export or convert it. Save source assets to refresh dependent previews.

Play destinations

Choose Docked, Joy Editor Tab, Browser Tab or Standalone Window, then press Play. Changing the destination alone does not launch it. Play focuses an existing session; Restart starts a fresh session in the selected destination. Stop returns to authoring.

Canvas focus and cameras

Click the tool canvas before using camera shortcuts. Drag to orbit; Shift-drag, right-drag or middle-drag to pan; scroll to zoom. With canvas focus, F frames the content and 0 resets the camera.
